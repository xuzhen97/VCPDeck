# ADR-0031：用户原生 Pi Session 的显式导入（首次受限读取）

- 状态：Proposed
- 日期：2026-09-23
- 决策者：项目维护者
- 关联：[ADR-0029](./0029-server-managed-isolated-pi-runtime.md)（决策 2/3 的唯一例外）、[`docs/design/remote-pi-control-plane.md`](../design/remote-pi-control-plane.md) §21、[`docs/design/remote-pi.md`](../design/remote-pi.md)、[`docs/security.md`](../security.md)

## 背景

ADR-0029 决策 2/3 硬性要求 VCPDeck Pi 与用户原生 Pi 零接触（唯一共享区域是用户明确选择的项目 cwd），并明确「不得扫描、列出、打开或修改用户原生 Pi Session」。隔离运行时上线后，用户在隔离之前的历史对话（包括 VCPDeck 隔离前写入 `~/.pi/agent/sessions` 的旧会话）从此无法在 VCPDeck 中访问。设计 §21.3 为此定义了「可选 Session 显式导入」，而它的动作恰恰是**只读地扫描、列出、打开**用户原生 Pi 会话——与上述绝对禁令冲突。需要一条**受控、可判定的唯一例外**，而不是让实现违反决策记录。

同时这是第一次允许读取用户个人 Pi 数据，读取面、写入面与正文泄漏面必须一次性定死。

## 决策

### 1. 显式导入是唯一允许接触用户原生 Pi 的路径

只允许在「用户主动发起的旧会话导入」中扫描、列出、只读打开用户原生 Pi 会话。任何其它路径（运行时会话管理、list/open/fork/clone、诊断、遥测）仍受 ADR-0029 决策 3 约束，禁止接触。

### 2. 读取面与标识

- 读取面严格限定为 `~/.pi/agent/sessions/**/*.jsonl`；源根由 Client 自身推导，**不接受参数覆盖**（杜绝「把任意目录当源读取」的原语）。`~/.pi` 其它任何内容（settings/models/auth/trust/skills 等）一律不得读取。
- 跨进程标识只接受**纯文件名**（不含 `/`、`\`、NUL，不为 `.` 或 `..`，长度 1–255），同名歧义即拒绝。

### 3. 只读、单向、只操作副本

- 源文件全程只读：不修改、不删除、不改名、不移动；
- 导入 = **单向复制**到 VCPDeck Session root（namespace 由会话记录的 cwd 派生，与该会话原属项目的新建会话同源），写入后做可解析校验，失败即清理半成品；
- 已存在同名副本即视为已导入（幂等），**永不覆盖**；此后只操作副本；
- 凭据、settings、models、trust 一律不迁移。

### 4. 正文红线

会话正文片段只允许出现在导入预览的响应中：**逐条显式确认**后才读取、80 字符截断；不进 Server 存储、Job payload/result、日志、审计或遥测。元数据摘要（文件名、时间、条目数、cwd）不含正文。

### 5. 持续约束

零污染门禁（用户 `~/.pi` 递归清单与内容 hash 0 created / 0 modified / 0 deleted）覆盖导入链路的全部动作（列目录、预览、导入），从一次性验证变为持续门禁。

## 候选方案

1. **自动迁移用户 Pi 会话**：设计 §21.1 明确否决——违背「用户主动选择」，且无差别扩大接触面；未选择。
2. **路径粘贴式导入**（用户填写 JSONL 路径）：读取面更小，但无法做 cwd 预校验与辨识度展示，易错且跳过了用户确认所需的信息基础；未选择。
3. **导出清单到浏览器挑选**：元数据与正文片段离开目标机，隐私面反而更大；未选择。
4. **回写源目录标注「已导入」**：任何回写都破坏零污染不变量；未选择（幂等依据改为目标侧同名文件）。

## 后果

正面：

- 用户历史对话可按需找回，且边界可判定、可由门禁验证；
- 「零接触用户 Pi」从绝对禁令收敛为「唯一受控例外」，语义更准确，实现不再违反决策记录。

负面与风险：

- 这是隐私边界的永久放宽：任何扩大读取面（读 settings、正文搜索）、自动化导入或回写源目录的诉求都必须新 ADR 处理并重新评审；
- 预览文本存在瞬时泄漏面（仅响应与 UI 内存），必须靠 canary 测试守住「不进存储/日志」；
- 同名歧义、损坏 JSONL 等异常一律 fail closed（拒绝导入），用户可能感知为「导不进来」。

## 验证与退出条件

- 导入前后用户 `~/.pi` 递归清单与内容 hash 0/0/0（零污染门禁）；
- 摘要响应不含正文与源文件完整绝对路径（canary）；
- 预览文本不出现在 Server 存储、Job payload/result、日志（canary）；
- `sourceName` 含路径逃逸字符时整请求被拒；
- 二次导入幂等且目标内容不变。

以下情况应重新评估：需要自动迁移、需要读取用户 Pi 的其它数据、需要把导入结果写回源目录、或多用户/跨信任域需求出现。
